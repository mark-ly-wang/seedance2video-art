This folder stores marketing-safe media assets.

Hero video assets (optimized):

- `hero-bg.mp4` → desktop fallback (H.264, ~10s, no audio)
- `hero-bg.webm` → desktop preferred (VP9, ~10s, no audio)
- `hero-bg-mobile.mp4` → mobile fallback (H.264, ~10s, no audio)
- `hero-bg-mobile.webm` → mobile preferred (VP9, ~10s, no audio)
- `hero-poster.jpg` → poster / fallback background image

Notes:
- Keep hero clips short (8–10s) and muted.
- Always export with `faststart` for MP4.
- Prefer WebM+MP4 dual-source for broad compatibility.
